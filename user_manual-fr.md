# Tabata — Manuel utilisateur

## 1. Créer un circuit

Depuis l'écran d'accueil, appuyez sur **Nouveau circuit**.

Renseignez les informations générales du circuit :

* **Nom** : nom du circuit.
* **Description** : description ou consignes générales.
* **Nombre de tours** : nombre de fois que le circuit sera répété.

Vous pouvez ensuite ajouter les exercices qui composent le circuit avec **Ajouter un exercice**.

### Ajouter un exercice

Pour chaque exercice, choisissez son type :

#### Manuel

Un exercice **Manuel** correspond à un exercice réalisé en comptant un nombre de répétitions.

Vous pouvez définir notamment :

* le nom de l'exercice
* une description ou des consignes
* le nombre de répétitions à effectuer
* le temps de repos
* le nombre de séries

#### Timer

Un exercice **Timer** correspond à un exercice réalisé pendant une durée déterminée.

Vous pouvez définir notamment :

* le nom de l'exercice
* une description ou des consignes
* la durée de l'exercice
* le temps de repos
* le nombre de séries

### Modifier l'ordre des exercices

Les exercices apparaissent dans l'ordre dans lequel ils seront exécutés.

Utilisez les commandes disponibles sur chaque exercice pour :

* modifier une exercice ![Crayon](https://www.androidicons.com/assets/images/ai-mdpi-black/ic_action_edit.png)
* copier une exercice ![Pages](https://www.androidicons.com/assets/images/ai-mdpi-black/ic_action_copy.png)
* supprimer une exercice ![Poubelle](https://www.androidicons.com/assets/images/ai-mdpi-black/ic_action_trash.png)
* déplacer une exercice vers le haut ou vers le bas ![Flèche haut](https://www.androidicons.com/assets/images/ai-mdpi-black/ic_action_arrow_top.png) ![Flèche bas](https://www.androidicons.com/assets/images/ai-mdpi-black/ic_action_arrow_bottom.png)

### Enregistrer le circuit

Appuyez sur **Enregistrer** pour sauvegarder le circuit.

Un circuit peut être enregistré même s'il n'est pas encore complètement défini. Vous pouvez ainsi le compléter ou le modifier ultérieurement.

# 3. Lancer un circuit

Depuis l'écran d'accueil, lancer le circuit ![Play](https://www.androidicons.com/assets/images/ai-mdpi-black/ic_action_playback_play.png).

Le circuit s'exécute automatiquement dans l'ordre défini lors de sa création.

Pour les exercices de type **Timer**, un compte à rebours indique le temps restant.

Pour les exercices de type **Manuel**, l'utilisateur doit manuellement indiquer la fin de sa série via le bouton **Série terminée**.

L'application annonce vocalement les différentes exercices afin de permettre de suivre le circuit sans avoir constamment besoin de regarder l'écran.

Le nombre de tours configuré pour le circuit est automatiquement pris en compte.

---

# 4. Pendant l'exécution

Pendant le circuit, le Runner affiche l'exercice actuellement exécutée et son état d'avancement.

Pour une exercice **Timer**, le temps restant est affiché et décompté automatiquement. Le décompte peut être interrompu à tout moment via le bouton **Pause**. Le décompte peut reprendre via le bouton **Reprendre**.

Les temps de repos sont également gérés par le Runner.

L'écran reste allumé pendant l'exécution du circuit afin de faciliter son utilisation pendant l'entraînement (pendant les décomptes plus particulièrement).

Un exercice peut être ignoré en appuyant sur le bouton **Suivant**.

---

# 5. Arrêter un circuit

Vous pouvez quitter l'éxécution du circuit à tout moment.

L'exécution du circuit est alors arrêtée.
